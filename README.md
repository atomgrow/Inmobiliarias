# Atomgrow · Inmobiliarias

Versión web estática del brochure de seis pantallas, lista para importar en AI Studio o publicar en un alojamiento que sirva archivos HTML.

## Archivos

- `index.html`: contenido y enlaces de contacto.
- `styles.css`: diseño adaptable a celular y escritorio.
- `assets/`: logo, tipografías e imágenes.
- `brochure.pdf`: versión PDF para compartir.

La página no requiere compilación ni dependencias. Al publicarla, usar `index.html` como entrada y conservar las rutas relativas de `styles.css` y `assets/`.

El documento incluye temporalmente `noindex, nofollow, noarchive` para evitar indexación durante la preparación. Quitar esa etiqueta de `index.html` cuando el dominio definitivo esté listo para aparecer en buscadores.

## Notas de contenido

La conversación de ejemplo es una simulación ilustrativa, no un caso real. Las fotos de Unsplash son imágenes ilustrativas aportadas por el usuario; no representan proyectos realizados por Atomgrow.
